Actividad5 — El modelo de caja en CSS

Introducción

Cuando un navegador muestra una página web, cada elemento HTML se representa internamente como una caja rectangular. Comprender cómo se compone y se dimensiona esa caja es uno de los conocimientos más importantes de CSS, porque de él dependen el espaciado, la alineación y, en general, toda la maquetación de una interfaz. Este concepto se conoce como el modelo de caja (box model).

En el contexto de PropertyStream Tech, el dominio del modelo de caja es esencial para optimizar la interfaz gráfica de herramientas como Smart Listings, donde la estructura visual de las páginas impacta directamente en la experiencia del usuario. Ajustar correctamente márgenes, bordes y rellenos permite crear diseños ordenados, responsivos y estéticamente agradables. Este informe investiga el concepto del modelo de caja y sus componentes, presenta ejemplos prácticos en HTML y CSS, y documenta cómo cada componente afecta el diseño. El entregable se sube además a un repositorio de GitHub, según lo solicitado.

¿Qué es el modelo de caja?

El modelo de caja es la forma en que CSS calcula el tamaño y el espacio que ocupa cada elemento. Toda caja está formada por cuatro áreas concéntricas, desde el centro hacia afuera: el contenido, el relleno (padding), el borde (border) y el margen (margin). Los componentes del modelo de caja

1. Contenido (content)

Es el área donde se muestra la información real del elemento: el texto, una imagen o cualquier otro contenido. Sus dimensiones se controlan con las propiedades width y height. Es la parte más interna de la caja.

2. Relleno (padding)

Es el espacio interno entre el contenido y el borde. Sirve para que el contenido "respire" y no quede pegado al borde. Se controla con padding y puede definirse para cada lado (padding-top, padding-right, etc.). El relleno toma el color de fondo del elemento.

3. Borde (border)

Es la línea que rodea el relleno y el contenido. Se controla con border, donde se define su grosor, su estilo (sólido, punteado, etc.) y su color. El borde separa visualmente el interior de la caja del espacio exterior.

4. Margen (margin)

Es el espacio externo que separa la caja de los elementos vecinos. Se controla con margin. A diferencia del relleno, el margen es transparente (no toma color de fondo) y puede colapsarse con los márgenes de elementos adyacentes.

La propiedad box-sizing

Por defecto, CSS usa box-sizing: content-box, lo que significa que el width declarado se refiere solo al contenido; el relleno y el borde se suman por fuera, aumentando el tamaño total. Esto suele causar confusión al maquetar.

La alternativa, box-sizing: border-box, hace que el width incluya el relleno y el borde, de modo que el tamaño total es exactamente el declarado. Por eso es muy común usar esta regla al inicio de la hoja de estilos:

* {
  box-sizing: border-box;
}
Modowidth declaradopaddingborderAncho real

Recomendación: usar border-box de forma global simplifica enormemente el cálculo de anchos y evita desbordamientos inesperados, sobre todo en diseños responsivos como los de Smart Listings.

Ejemplo práctico 1: las cuatro áreas

El primer ejemplo muestra visualmente las cuatro áreas de la caja usando colores distintos para cada una. El código HTML anida varios <div> y el CSS les aplica relleno y fondo para que cada capa sea visible.

<div class="caja-margin">
  <div class="caja-border">
    <div class="caja-padding">
      <div class="caja-content">content</div>
    </div>
  </div>
</div>
.caja-margin  { background:#f4d35e; padding:26px; } /* margen  */
.caja-border  { background:#ee964b; padding:22px; } /* borde   */
.caja-padding { background:#90be6d; padding:22px; } /* relleno */
.caja-content { background:#577590; color:#fff; padding:24px 36px; } /* contenido */

Ejemplo práctico 2: tarjetas de propiedad

El segundo ejemplo aplica el modelo de caja a un caso real de Smart Listings: tarjetas de propiedades. Cada tarjeta usa margin para separarse de las demás, border para delimitarse y padding para dar aire al contenido interno.

.tarjeta {
  background: #f2f2f2;
  margin: 8px;               /* separación entre tarjetas */
  border: 2px solid #1f3b5c; /* borde delimitador */
  padding: 16px;             /* espacio interno */
  border-radius: 8px;
  width: 200px;
}

Al modificar estos tres valores cambia por completo la sensación visual: más padding da amplitud, más margin separa los elementos, y el border aporta definición. Ajustarlos bien es clave para una interfaz limpia.

Ejemplo práctico 3: comparación de box-sizing

El tercer ejemplo compara dos cajas con el mismo width:200px, padding:20px y border:3px, pero con distinto box-sizing. La primera (content-box) termina midiendo 246px de ancho; la segunda (border-box) mide exactamente 200px.

.caja-content-box { box-sizing: content-box; } /* ancho real 246px */
.caja-border-box  { box-sizing: border-box;  } /* ancho real 200px */

Cómo cada componente afecta el diseño

Cada parte del modelo de caja cumple un papel concreto en la maquetación:

  • Contenido: determina el tamaño base del elemento; de él parte todo el cálculo.
  • Relleno: mejora la legibilidad al separar el contenido de los bordes; demasiado poco hace que el texto se vea apretado, demasiado lo desperdicia.
  • Borde: aporta estructura y jerarquía visual; ayuda a distinguir componentes como tarjetas, botones o campos de formulario.
  • Margen: controla el ritmo y la respiración del diseño; un buen uso del margen evita que la interfaz se vea saturada.

En conjunto, estos cuatro componentes permiten lograr diseños equilibrados, responsivos y agradables. En una plataforma como Smart Listings, un uso cuidadoso del modelo de caja se traduce directamente en una interfaz más clara y en una mejor experiencia de usuario.

Conclusión

El modelo de caja es un concepto fundamental de CSS que explica cómo se compone y se dimensiona cada elemento de una página: contenido, relleno, borde y margen. Comprender el papel de cada componente, así como el efecto de la propiedad box-sizing, es indispensable para construir interfaces ordenadas, responsivas y estéticamente agradables. Aplicado al proyecto Smart Listings de PropertyStream Tech, el dominio del modelo de caja permite optimizar la interfaz gráfica y mejorar la experiencia del usuario, integrándose con los datos de Firebase y la gestión de versiones de GitHub.
